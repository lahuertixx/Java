Tema 1 · Java

                                
Variables y tipos

                                
Una variable es un espacio con nombre donde guardamos un valor. En Java hay que decir siempre de qué tipo es: int para enteros, double para decimales, String para texto, boolean para verdadero/falso y char para un carácter.

                                
int edad = 16;
double nota = 8.5;
String nombre = "Martin";
boolean aprobado = true;
char inicial = 'M';
System.out.println(nombre + " tiene " + edad + " años");

                                
Para qué sirve: es la base de todo programa. saber elegir el tipo evita errores, por ejemplo usar int para una nota con decimales te perdería el 8.5.

                            


                            

                                
Tema 2 · Java

                                
Entrada de datos con Scanner

                                
Scanner lee lo que escribe el usuario por teclado. Primero se importa, luego se crea el objeto y después se usa nextLine() para texto o nextInt() para enteros.

                                
import java.util.Scanner;

public class Datos {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        System.out.print("Tu nombre: ");
        String nombre = teclado.nextLine();
        System.out.print("Tu edad: ");
        int edad = teclado.nextInt();
        System.out.println("Hola " + nombre + ", tienes " + edad);
    }
}

                                
Para qué sirve: hace que los programas interactúen con quien los usa. Aparece en casi todos los ejercicios del repositorio: FichaAlumno, MiMatricula, MiEscaner…

                            


                            

                                
Tema 3 · Java

                                
Condicionales: if / else

                                
Sirven para tomar decisiones. Si la condición es verdadera se ejecuta el primer bloque; si no, pasa al else if o al else. Se comparan con ==, <, >, <=, >= y !=.

                                
int nota = 7;
if (nota < 5) {
    System.out.println("Insuficiente");
} else if (nota < 7) {
    System.out.println("Bien");
} else {
    System.out.println("Notable o más");
}

                                
Para qué sirve: para clasificar resultados o validar datos. Lo ves en Problema_05 (notas) y en MiPrueba (mayor o menor de edad).

                            


                            

                                
Tema 4 · Java

                                
Bucles: for, while y do-while

                                
Un bucle repite código. for se usa cuando sabes cuántas veces; while mientras se cumpla una condición; do-while al menos una vez sí o sí, porque comprueba al final.

                                
// del 1 al 5
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

// pedir un número válido (al menos una vez)
int n;
do {
    System.out.print("Del 1 al 10: ");
    n = teclado.nextInt();
} while (n < 1 || n > 10);

                                
Para qué sirve: para repetir sin escribir lo mismo mil veces y para validar entradas. Está en Problema_02, Problema_07 y Problema_11.

                            


                            

                                
Tema 5 · Java

                                
Arrays y cadenas

                                
Un array guarda varios valores del mismo tipo en posiciones que empiezan en 0. Un String es una cadena de texto con métodos como length(), charAt() o equals().

                                
int[] notas = {5, 7, 9};
System.out.println(notas[0]);        // 5
System.out.println(notas.length);    // 3

String nombre = "Lahuertix";
System.out.println(nombre.length()); // 9
System.out.println(nombre.charAt(0));// L

                                
Para qué sirve: para trabajar con listas de datos, como las mediciones de Problema_03 o los productos de MisDatos.

                            


                            

                                
Tema 6 · Java

                                
Clases y objetos

                                
Una clase es el molde; un objeto es una instancia de ese molde. Los atributos guardan su estado y los métodos su comportamiento. El constructor se llama igual que la clase y sirve para inicializar.

                                
public class Contador {
    int valor;
    public Contador() { valor = 0; }
    public void incrementar() { valor++; }
    public int consultarValor() { return valor; }
}

Contador c = new Contador();
c.incrementar();
System.out.println(c.consultarValor()); // 1

                                
Para qué sirve: para organizar programas grandes y reutilizar código. Es exactamente lo que hace tu archivo Contador.java.

HTML (se verá más adelante)

                                
HTML no es un lenguaje de programación, es de marcado: describe la estructura de una página con etiquetas. Esta web ya está hecha con él, así que puedes practicar en la pestaña HTML de la zona interactiva.

Tema 8 · Programación

                                
Algoritmos y resolución de problemas

                                
Un algoritmo es una sucesión ordenada y finita de pasos para resolver un problema. El trabajo se divide en analizar el problema, diseñar el algoritmo, implementarlo y mantenerlo.

                                
1. Leer tres números
2. Sumarlos
3. Dividir la suma entre 3
4. Mostrar la media

                                
Para qué sirve: separar «qué hay que hacer» de «cómo se escribe en Java» evita errores. Técnicas útiles: hacer preguntas, buscar semejanzas, dividir y vencer, y probar con datos pequeños.

                            


                            

                                
Tema 9 · Programación

                                
Java: JDK, compilación y estructura

                                
El JDK incluye el compilador javac y la JVM. El código fuente .java se compila a bytecode .class y la JVM lo ejecuta. El método main es el punto de entrada.

                                
javac MiPrimerPrograma.java
java MiPrimerPrograma

                                
Para qué sirve: el mismo programa funciona en Eclipse, IntelliJ o VS Code porque quien compila es el JDK; el IDE solo ayuda a escribir y organizar el código.

                            


                            

                                
Tema 10 · Programación

                                
Tipos, literales y estructuras de control

                                
Java dispone de enteros, decimales, caracteres, cadenas y booleanos. Los literales pueden escribirse en decimal, hexadecimal (0x), octal (0) o binario (0b); para long se usa el sufijo L.

                                
int n = 0b1010;            // 10
long grande = 5_000_000_000L;
if (n > 5) {
    System.out.println("mayor que 5");
}
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

                                
Para qué sirve: elegir el tipo correcto evita perder información (por ejemplo, usar int para una nota con decimales) y los bucles permiten repetir sin copiar código.

                            


                            

                                
Tema 11 · Programación

                                
Fundamentos de la programación orientada a objetos

                                
Una clase es la plantilla y un objeto es una instancia creada con new. La abstracción muestra solo lo relevante y la encapsulación protege el estado interno. Las referencias están en la pila (stack) y los objetos en el montón (heap).

                                
public class Contador {
    private int valor;
    public void incrementar() { valor++; }
    public int consultarValor() { return valor; }
}

Contador c = new Contador();
c.incrementar();
System.out.println(c.consultarValor()); // 1

                                
Para qué sirve: organizar programas grandes, reutilizar código y controlar qué se puede modificar desde fuera de la clase.

                            


                            

                                
Tema 12 · Bases de datos

                                
Bases de datos y SGBD

                                
Una base de datos guarda datos relacionados con la menor redundancia posible; el SGBD es el software que los define, administra y consulta. Los niveles de abstracción son interno (cómo se guarda), conceptual (estructura global) y externo (lo que ve cada usuario).

                                
CREATE TABLE Alumno (id INT PRIMARY KEY, nombre VARCHAR(50));
INSERT INTO Alumno VALUES (1, 'Ana');
SELECT nombre FROM Alumno WHERE id = 1;
GRANT SELECT ON Alumno TO profesor;

                                
Para qué sirve: DDL crea estructuras (CREATE, ALTER, DROP), DML mueve datos (SELECT, INSERT, UPDATE, DELETE) y DCL gestiona permisos (GRANT, REVOKE).

                            


                            

                                
Tema 13 · Bases de datos

                                
Modelo entidad-relación

                                
En el diseño conceptual se representan entidades, atributos y relaciones con su cardinalidad. Una entidad débil depende de otra para identificarse; una jerarquía ISA especializa una entidad en subtipos excluyentes o solapados.

                                
MAQUINARIA ---tiene---> PARTE_AVERIA (débil)
EMPLEADO <--- ISA --- MECANICO | OPERADOR
antiguedad = fecha_actual - fecha_alta  (derivado)

                                
Para qué sirve: convertir un enunciado en tablas SQL sin perder información: detectar claves, relaciones 1:N o N:M y atributos compuestos o multivaluados antes de crear el esquema.

                            


                            

                                
Tema 14 · Sistemas informáticos

                                
Sistemas operativos e instalación

                                
El sistema operativo gestiona hardware, procesos, memoria, archivos y dispositivos. Puede ser monousuario o multiusuario, mono o multitarea, de red, embebido o de tiempo real. Antes de instalar hay que revisar requisitos, preparar el almacenamiento y el medio de arranque.

                                
uname -r
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
sudo apt update && sudo apt upgrade

                                
Para qué sirve: la virtualización permite probar un sistema sin tocar el equipo real, y las copias de seguridad con puntos de restauración permiten recuperarse de un fallo.

                            


                            

                                
Tema 15 · Digitalización

                                
Digitalización, Industria 4.0 y entornos IT/OT

                                
Digitalizar es pasar información a formato digital; digitalizar procesos es cambiar cómo se hacen; la transformación digital replantea la organización. IT es el negocio (ERP, CRM, SGBD) y OT es la planta (sensores, PLC, HMI, SCADA).

                                
papel → escaneo → PDF        (digitalización de información)
pedido → datos → registro → responsable  (digitalización de proceso)
IT (oficina) <── integración ──> OT (producción)

                                
Para qué sirve: entender de dónde salen los datos que luego guardamos en una base de datos y por qué conectar IT y OT reduce esperas y errores.

                            


                            

                                
Tema 16 · Entornos de desarrollo

                                
IDE, JDK, Maven, Git y Scrum

                                
VS Code es un editor que necesita extensiones para Java; IntelliJ y Eclipse son IDE con muchas funciones integradas. En los tres el JDK compila el mismo código y Maven gestiona dependencias y ciclo de vida. Git controla versiones y Jira/Scrum organiza el trabajo en sprints.

                                
git clone https://github.com/lahuertixx/Java.git
git status
git add .
git commit -m "Añadir apuntes"
git push

                                
Para qué sirve: saber qué hace cada herramienta: el IDE edita, el JDK compila, Maven construye, Git guarda versiones y el backlog decide qué se hace en cada sprint.

                            


                            

                                
Tema 17 · Lenguaje de marcas

                                
De SGML a HTML y XML

                                
Un lenguaje de marcado describe la estructura del contenido con etiquetas; no es un lenguaje de programación porque no ejecuta instrucciones. HTML deriva de SGML y XML es un metalenguaje usado para definir otros formatos.

                                
<?xml version="1.0" encoding="UTF-8"?>
<alumno>
  <nombre>Ana</nombre>
  <nota>8.5</nota>
</alumno>

                                
Para qué sirve: distinguir una etiqueta (apertura, cierre y atributos) de una sentencia Java; es la base para leer el HTML de esta web.

                            


                            

                                
Tema 18 · Lenguaje de marcas

                                
HTML y XHTML: estructura y formularios

                                
HTML define el contenido de una página con elementos formados por etiquetas de apertura, cierre y atributos. XHTML es más estricto: todo se cierra, las etiquetas van en minúsculas y los atributos entre comillas.

                                
<table>
  <tr><th>Asignatura</th><td>Programación</td></tr>
</table>
<form action="/enviar" method="post">
  <label for="nombre">Nombre</label>
  <input id="nombre" name="nombre" required />
</form>

                                
Para qué sirve: crear tablas, formularios y contenido multimedia con marcado válido y semántico; es la base de LAHU PAGE.
